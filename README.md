# Business Sales Prediction Dashboard

An interactive machine learning dashboard that explores business
data and predicts sales based on advertising spend, price,
economic conditions, and competition.

## Features

- Interactive sales predictions
- Sales data exploration and visualisations
- Correlation heatmap
- Actual vs predicted sales comparison
- Residual analysis
- Model coefficients and evaluation metrics
- Downloadable reports and data

## Technologies Used

- Python
- Streamlit
- Pandas and NumPy
- Plotly
- Scikit-learn
- Statsmodels

## Run Locally

1. Download or clone this repository.
2. Install the required libraries:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start the dashboard:

   ```bash
   python -m streamlit run app.py
   ```

## Dataset

The dashboard reads `data.csv` from the project folder.
Keep the dataset in the same folder as `app.py`.

## Disclaimer

Predictions are estimates based on the available dataset.
They should not be treated as guaranteed business outcomes.
